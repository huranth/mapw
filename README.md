# mapw

A multi-pane terminal workspace for Windows. One to a hundred shells on a freeform canvas — command blocks with exit codes, saved layouts, one-click AI CLIs. Local-first: no account, no telemetry of your content, settings live in one JSON file you own.

## Download

Grab the latest installer from [Releases](https://github.com/huranth/mapw/releases). One portable exe — no installer steps, no admin. The app updates itself in the background and verifies every download against the published SHA256.

- Website: https://mapw.vercel.app
- Docs: https://mapw.vercel.app/docs
- Privacy: https://mapw.vercel.app/privacy

## Highlights

- **Panes on a canvas** — drag, resize, tidy into a grid; minimap beyond twelve panes
- **Command blocks** — every command keeps its output, exit code, and timestamp
- **AI CLI chips** — Claude, Codex, Gemini, OpenCode, Aider, Amp launch into the pane they're pinned to
- **Layouts** — save any arrangement, apply it any time
- **Local-first** — commands, output, and files never leave your machine

## Requirements

Windows 11 x64. PowerShell 5.1 and 7, cmd, and Git Bash work out of the box.
